MEU TREINO - versão inicial

Como usar:
1. Abra index.html no navegador para testar.
2. Para instalar como aplicativo no iPhone, a aplicação precisa estar hospedada em um endereço HTTPS.
3. No Safari do iPhone: Compartilhar > Adicionar à Tela de Início.

Esta primeira versão salva os registros no armazenamento local do navegador.
